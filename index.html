Projects

Haoko Closed

Haoko is a compact terminal utility written in C++ during the transition to Arch Linux. It includes an active player parser via MPRIS, search by author and track title via the lrclib.net API, and retrieval (if available) of synchronized lyrics and their subsequent display in the terminal. The project was inspired by some guy from TikTok.

Bifrost Closed

Bifrost was created to easily transfer files over a local network between a computer and a phone, replacing notes or cloning messages in messengers. It includes Qt integration with the Quickshell shell and a backend written in C++, enabling incredibly fast transfers thanks to optimized UDP Transfer. It also includes a web server with QR code access for guests.

Kairos Closed

Kairos was conceived as a complement to Haoko due to the lack of lip-synch for many songs on lrclib.net. It is based on OpenAI Whisper models of varying complexity: Base, Medium, and Turbo. Technologies such as VAD (silence recognition), STEM separation (separating beats from vocals in a track), and multilingual support were added. The project was abandoned due to its limited versatility: each track requires an individual approach, poor ad-lib recognition, repetitive lyrics, etc.

Raze Closed

Raze was a military-political Minecraft server running version 1.20.1, created and released to the public in December 2025. Developed by myself, the entire server logic was written in Java and compiled into a single mod. The server featured a single PvP mode, Annihilation, with the destruction of military aircraft control points. The project was closed in January 2026 due to financial inability to maintain the server.

ecco Closed

ecco is a solo experimental project created in February 2026 by myself. It is a universal Telegram bot for downloading high-quality media content from various platforms, such as YouTube, TikTok, Instagram, Pinterest, and SoundCloud. The project is written in Python and uses the yt-dlp library. Downloading from YouTube was suspended after a week due to accessibility issues. The project was closed due to its lack of relevance and the release of the server in favor of other projects.

H.S.B Active

H.S.B (Halyava Seeker Bot) is a Telegram bot created in 2026 by myself for discovering free and discounted games across multiple platforms, including Steam, Epic Games Store, GamerPower, and itch.io. Written in Python using the aiogram framework, the bot features automated giveaway tracking, new release notifications filtered by genre preferences, and a personal wishlist system with price drop alerts. The bot supports multiple languages and currencies, with scheduled background checks running every 30 minutes to 6 hours depending on the data source. The bot is available on Telegram under the username @HSB_Pidorbot

SixteenCloud Active

SixteenCloud is a custom, unofficial SoundCloud fork with removed ads, regional restriction bypass, Discord Rich Presence, OAuth Token Login, a built-in track downloader, and many useful features. Created by me in April 2026, it's now live. Download it here.

MIMIC Closed

MIMIC is a full-stack SaaS I built from April to July 2026: an autonomous Telegram persona-clone agent. It connects to a user's Telegram account via MTProto and replies in selected chats so the other person shouldn't realize they're talking to a bot. The core is a behavioral engine — typing jitter, sleep schedule, delayed replies, read-skip, reactions — plus Human-in-the-Loop escalation for risky topics, PersonaBible profiles, RAG over real chat history with e5 embeddings, CryptoBot billing, and a Telegram Mini-App for control. Backend in Python (Pyrogram, aiogram, FastAPI) with Postgres, Redis, and Qdrant; TMA frontend in React and TypeScript. The project was completed and handed off in July 2026.
